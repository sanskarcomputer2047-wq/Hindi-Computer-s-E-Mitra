⌨️ कंप्यूटर शॉर्टकट कीज़ & कुर्ती देव (Kruti Dev 010) फॉन्ट गाइड

📌 महत्वपूर्ण MS Word / Excel शॉर्टकट कीज़:

  • Ctrl + C: कॉपी (Copy)
  • Ctrl + V: पेस्ट (Paste)
  • Ctrl + Z: अन-डू (Undo)
  • Ctrl + Y: री-डू (Redo)
  • Ctrl + A: ऑल सिलेक्ट (Select All)
  • Ctrl + P: प्रिंट (Print Window)
  • F2 (In Excel): सेल एडिट करें
  • Alt + = (In Excel): ऑटो सम (AutoSum)

📌 कुर्ती देव 010 (Kruti Dev) स्पेशल आल्ट कोड्स (Alt Codes):

• क्र (kr): Alt + 0216  |  • ट्ट (tt): Alt + 0199  |  • द्ध (ddh): Alt + 0224

• द्य (dya): Alt + 0225  |  • ष्ट (sht): Alt + 0197  |  • उद्धरण चिन्ह (" "): Alt + 034

• ऊ (Uu): Alt + 0197  |  • फ्र (Fra): Alt + 0221  |  • हाफ - (Hyphen): Alt + 0173

📢 न्यू वैकेंसीज़, ऑनलाइन फॉर्म & ज़रूरी डॉक्यूमेंट्स

राजस्थान की अधिकांश भर्तियों (RPSC, RSSB, CET आदि) के ऑनलाइन आवेदन *SSO Portal (OTR - One Time Registration)* के माध्यम से भरे जाते हैं।

📄 ऑनलाइन फॉर्म भरने हेतु आवश्यक दस्तावेज़ (Checklist):

  • जनाधार कार्ड / आधार कार्ड (नाम, जन्मतिथि और पिता का नाम 10th मार्कशीट से मैच होना चाहिए)
  • 10th, 12th एवं स्नातक (Graduation) की मार्कशीट
  • जाति प्रमाण पत्र (Caste Certificate) एवं मूल निवास (Domicile)
  • पासपोर्ट साइज नवीनतम फोटो (सफेद या हल्के बैकग्राउंड में) एवं हस्ताक्षर (Sign)
  • मोबाइल नंबर एवं ई-मेल आईडी (ओटीपी सत्यापन के लिए)
  • RS-CIT या कंप्यूटर डिप्लोमा सर्टिफिकेट (जहाँ आवश्यक हो)
